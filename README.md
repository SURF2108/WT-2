## StudyStack

StudyStack is a responsive study-task planner built with plain HTML, CSS, and JavaScript. Open `index.html` in a browser to use it.

- Add tasks with a subject, due date, estimated study time, and priority.
- Search tasks, filter by completion, mark them done, or delete them.
- View task, remaining-time, and completed-task summaries.
- Tasks are kept in a JavaScript array and serialized as JSON in browser `localStorage`.
- The form validates required fields, text lengths, dates, and study-time limits before saving, and shows field-specific error messages.
